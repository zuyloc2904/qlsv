# QLSV - Student Management and Monitoring

## Giới thiệu
Dự án quản lý sinh viên triển khai bằng Docker Compose,
kết hợp giám sát hệ thống và quản lý log.

## Công nghệ
- PHP
- MySQL
- Nginx
- Docker Compose
- Prometheus
- Grafana
- Loki

## Khởi chạy
Tại thư mục dự án, chạy:

```bash
docker compose up -d
